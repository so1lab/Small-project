# 大肥鱼资料归档 0.9.0

普通投放即归档。先匹配有证据的项目；项目不明时，DeepSeek 选择已有用途目录或给新用途命名。常见同义名统一，如海报归宣传素材、来电归往来沟通。模型不可用时按本地用途线索或格式收纳。已存文件可在总览调整分类。双击打开总览，Alt 投放可选择手动搬运或回收站。

参考上游 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，适配 Windows dsh-pet 0.4.7 与 Python 3.10+。组件为 MIT 许可证。宿主模型会收到新文件和相关历史记录的有限文本片段。

退出桌宠后运行 python install.py 插件目录，随后重启 DSH。卸载时追加 --uninstall。
